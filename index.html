One spacecraft, every subject.

A small satellite must work out which way it is pointing and then hold that attitude against disturbances, using nothing but three small reaction wheels. Almost every subject studied, from mechanics and mathematics to software, statistics and human factors, feeds that one control loop.

The loop, block by block

This is the project's attitude-control loop, drawn the way control engineers draw it. Signals run left to right from the target attitude to the spacecraft, and the spacecraft's state comes back to be compared with the target. Around the loop sit the parts that say what it must achieve, prove that it does, and build and run it. Every block lists the subjects whose material feeds it.

One pass around the loop, every 0.01 s

  1. compares the attitude \(q\) with the target: \(q_e = q_{ref}^{*} \otimes q\), flipped if needed so that it describes the shorter rotation. Its angle \(\theta_e = 2\,\mathrm{atan2}(\lVert q_{e,v}\rVert,\, q_{e0})\) is the pointing error, and the rate norm \(\lVert\omega\rVert\) is computed from the same state.
  2. compares \(\lVert\omega\rVert\), the error angle and the fault flag with its thresholds and picks the control law. NOMINAL holds the target; if \(\lVert\omega\rVert\) exceeds 6 deg/s, or a fault persists for 0.5 s, it switches to SAFE_DETUMBLE, then to SAFE_HOLD, before it hands back. Project
  3. turns the error and the body rate \(\omega\) into a torque command with the law the mode manager has just chosen. In NOMINAL that is a PID law, \(\tau_{cmd} = -K_p\,q_{e,v} - K_d\,\omega - K_i \int q_{e,v}\,dt\), with torque in N m.
  4. clip each axis to ±3 mN m Project, so a large error asks for more torque than the wheels can give.
  5. add the 's disturbance torque and evolve the rigid body: \(J\dot\omega + \omega \times (J\omega) = \tau + \tau_d\) for the rates and \(\dot q = \tfrac12\, q \otimes [0, \omega]\) for the attitude.
  6. advances the state by one RK4 step of 0.01 s Site default and renormalises \(q\) to unit length.
  7. The loop closes. The original project fed the true simulated state straight back to the error quaternion; the dashed and replace it with noisy measurements and a filter. Extension

The order is not arbitrary. The mode guards read this step's error angle and rate, so the errors must exist before the mode logic runs, and the controller must run after it so that it uses the mode just chosen. Module 02 turns one time step into an ordering puzzle.

    How to read this site

    Every number and every claim carries a label that says where it comes from: stated in the project notes, derived from them, or chosen by this site. Open the legend for the full list.

    Typical content means a link rests on the standard syllabus of a subject with that name, inferred from its outline, and not on notes from the subject itself. Analogy marks a teaching bridge, such as reading a residual network block as one forward-Euler step, which helps an idea cross between fields without claiming the subject taught it. Extension marks work beyond the original project, above all the sensors and estimator, because the original project fed its controller the true simulated state.
