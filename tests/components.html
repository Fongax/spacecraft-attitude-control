Typography and layout

A lede paragraph introduces a page in one or two sentences.

Body text runs at 16px with a line height of 1.6 inside .prose (72 characters wide). Links look like this, keys like Space and ←, inline code like ADCS.sim.run(config), and highlighted search hits like quaternion.

Plots

Hover or tap for values, click to seek, focus a plot and use ← → (with Shift for bigger steps). Legend buttons hide and show series. Every plot has a Data (CSV) button and a text summary.

Code

Wireframe

Drag, or focus it and use the arrow keys, to rotate the camera; double-click or Home resets it. The scrub slider in "Simulation displays" drives the attitude.

Code
const w = ADCS.wire.create(canvas, { trail: 300, view: { az: -35, el: 22 } });
w.setQuat(sample.q);
w.setArrows([{ v: [wx, wy, wz], frame: 'body', color: '--accent', label: 'ω' }]);

Equations and glossary terms

Inline maths such as \(\dot q = \tfrac12\, q \otimes [0, \omega]\) and a display equation in an .eq block:

\[ J\dot{\omega} + \omega \times J\omega = \tau + \tau_d, \qquad K = R^{-1}B^{\mathsf T}P \]

A long display equation scrolls inside its box at 360px:

\[ q_e = q_{ref}^{*} \otimes q, \quad \theta_e = 2\,\operatorname{atan2}\!\left(\lVert q_{e,v} \rVert,\; q_{e,0}\right), \quad \tau_{cmd} = -K_p\, q_{e,v} - K_d\,\omega - K_i \int q_{e,v}\,dt, \quad |\tau_i| \le 0.003\ \mathrm{N\,m} \]

Glossary terms become links with a definition tooltip: the LQR weighs state error against effort, and the quaternion avoids gimbal lock.
