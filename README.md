# Spacecraft Attitude Control: The Big Picture

An interactive, educational website about spacecraft attitude determination and control (ADCS). It rebuilds a student attitude-control simulation project in the browser and shows how subjects from mechanical engineering, mathematics, physics, computer science, AI and data, programming, aviation, and management and human factors each feed one part of the problem.

## What's inside

- A 3D simulator: rigid-body quaternion dynamics, PID / LQR / detumble controllers, reaction-wheel torque limits, a safe-mode state machine, fault injection, requirement checks and a Monte Carlo runner.
- Thirteen learning modules in engineering-lifecycle order, from requirements through operations, each with interactive widgets and a "where this came from" box.
- An atlas that maps every subject to the parts of the project it supports, and a glossary.

## Running it

It is a plain static site with no build step. Open `index.html` in a browser, or serve the folder with any static server. It is published with GitHub Pages from the repository root.
